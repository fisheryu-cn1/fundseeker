# 多期持仓变化分析建议

## 1. 背景与目标

当前系统已能通过东方财富等数据源采集公募基金的季度/年度持仓明细，并沉淀到 `holding_report`、`product_holding`、`product_asset_allocation`、`product_holding_summary` 等表中。随着持仓数据跨越多个报告期积累，同一产品在不同时间点的持仓变化将具备独立的分析价值。

本建议基于现有表结构与相似性/归因模块，梳理可以从“单产品多期持仓变化”中衍生出的分析维度、计算指标、业务场景及落地建议，供后续功能扩展参考。

## 2. 数据基础

| 表 | 可用字段 | 说明 |
|---|---|---|
| `holding_report` | `report_date`, `report_type`, `report_period` | 报告期锚点 |
| `product_holding` | `asset_code`, `asset_name`, `asset_type`, `sub_type`, `market`, `industry_code`, `industry_name`, `weight`, `market_value`, `share_quantity`, `is_top10`, `sort_order` | 个股/债券等明细 |
| `product_asset_allocation` | `asset_class`, `weight`, `market_value` | 大类资产配置 |
| `product_holding_summary` | `top10_weight`, `stock_weight`, `bond_weight`, `cash_weight`, `fund_weight`, `derivative_weight`, `non_standard_weight`, `other_weight`, `concentration_score`, `holding_count`, `turnover_indicator` | 汇总指标 |

分析对象：同一 `product_id` 连续多个 `report_date` 的持仓快照。

## 3. 建议分析维度

### 3.1 持仓稳定性分析

衡量基金经理调仓积极程度与持股耐心。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 股票换手率（Stock Turnover） | 基于权重变化或数量变化计算，例如 `sum(|w_t - w_{t-1}|) / 2` | 越高说明调仓越频繁 |
| 重仓股重叠系数（Overlap） | `sum(min(w_t, w_{t-1}))`，与 `similarity.py` 的 `overlap_coefficient` 一致 | 越接近 1 越稳定 |
| 重仓股 Jaccard 相似度 | `intersection(非零持仓) / union(非零持仓)` | 只看持股集合，不看权重 |
| 持股数量变化 | `holding_count_t - holding_count_{t-1}` | 持仓广度变化 |
| 连续重仓期数 | 某只股票连续出现在 top10 的报告期数 | 识别核心底仓 |

应用场景：筛选“低换手、高胜率”的耐心型产品，或识别“风格漂移、高频调仓”的产品。

### 3.2 集中度变化分析

判断基金是否在集中押注或分散风险。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| Top10 权重变化 | `top10_weight_t - top10_weight_{t-1}` | 正向为更加集中 |
| HHI 集中度变化 | `concentration_score` 跨期比较 | 识别集中度骤升/骤降 |
| 第一大重仓权重变化 | 单只股票最大权重跨期变化 | 识别押注式调仓 |
| 前 3 / 前 5 大重仓合计占比 | 按 `sort_order` 汇总 | 判断核心仓位稳定性 |

应用场景：集中度快速上升叠加单一行业加仓，可能预示主题押注；快速分散可能预示防御或看不清方向。

### 3.3 行业与资产配置漂移

捕捉基金在行业或大类资产上的迁移。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 行业权重变化矩阵 | 按 `industry_name` 聚合 `weight` 后做差分 | 识别加仓/减仓行业 |
| 行业 HHI 变化 | 行业权重向量的 HHI 跨期比较 | 行业集中度变化 |
| 大类资产权重变化 | `stock_weight`, `bond_weight`, `cash_weight` 等跨期差分 | 股债仓位择时 |
| 行业切换数量 | 新进入前三大行业的数量 | 调仓剧烈程度 |

应用场景：识别“追逐热点”型产品（行业快速轮动），或“坚守能力圈”型产品（行业稳定）。

### 3.4 重仓股异动分析

基于个股维度识别买卖行为。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 新进入重仓 | 本期 top10 中上期未出现 | 新增看好标的 |
| 退出重仓 | 上期 top10 中本期未出现 | 不再看好或获利了结 |
| 增持 / 减持 | `weight_t - weight_{t-1}` | 加仓/减仓幅度 |
| 隐形增持 | 不在 top10 但 `share_quantity` 或 `market_value` 明显增加 | 可能被忽视的调仓 |
| 持股周期分布 | 统计所有持仓股票连续出现的报告期数 | 偏好长期持有还是短线交易 |

应用场景：生成“季度十大变化”报告，快速定位基金经理的最新调仓方向。

### 3.5 投资风格漂移分析

将持仓特征映射到常见风格标签，观察时序一致性。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 价值/成长风格迁移 | 基于重仓股市盈率、行业属性打分（需外部数据） | 识别风格漂移 |
| 大盘/小盘迁移 | 基于流通市值分位或行业龙头属性 | 市值风格变化 |
| 主题集中度 | 某主题（如 AI、红利、消费）权重占比跨期变化 | 是否追逐主题 |
| 行业偏离基准 | 相对沪深300/中证800的行业超低配 | 主动管理程度 |

应用场景：与招募说明书中的“投资风格”对比，判断是否言行一致；识别风格漂移导致的收益波动。

### 3.6 相似性网络的时序变化

复用现有 `similarity.py` 的能力，观察产品与外部对象的距离变化。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 与同类产品相似度变化 | 与同类基金持仓的 `overlap`/`cosine` 时序 | 是否从同质化走向差异化 |
| 与基准指数相似度变化 | 与沪深300等指数成分权重的相似度 | 指数化/主动化程度 |
| 与上期自身相似度 | 自相似度下降意味着调仓剧烈 | 自我稳定性 |
| 同簇成员稳定性 | 聚类结果中同簇产品跨期变化 | 风格归属变化 |

应用场景：识别“曾经很独特、现在很平庸”的产品，或“从大盘蓝筹切换到主题成长”的风格转换。

### 3.7 绩效归因的跨期比较

复用现有 `similarity/attribution.py` 的 Brinson 归因，将结果按报告期串联。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 配置效应时序 | 各期 `allocation_effect` 变化 | 行业择时能力稳定性 |
| 选股效应时序 | 各期 `selection_effect` 变化 | 个股 alpha 能力稳定性 |
| 超额收益持续性 | 跨期 `excess_return` 自相关或胜率 | 业绩是否可持续 |
| 同簇排名变化 | 各期 `rank_in_cluster` 变化 | 在同类中相对表现 |

应用场景：区分“靠行业轮动赚钱”与“靠选股赚钱”的基金经理，并判断其能力是否稳定。

### 3.8 异常与信号检测

基于跨期变化识别值得关注的信号。

| 信号 | 判定规则示例 | 用途 |
|---|---|---|
| 行业大漂移 | 单一行业权重一期变化 > 10% | 主题切换预警 |
| 集中度骤变 | `top10_weight` 一期变化 > 15% | 策略或基金经理变更信号 |
| 换手率异常 | 换手率高于历史均值 2 倍标准差 | 调仓异常 |
| 新基金经理痕迹 | 重仓股大换血且与上任风格迥异 | 人事变动提示 |
| 风格漂移告警 | 连续两期风格标签与招募说明书不符 | 合规/投资者教育 |

应用场景：构建监控看板，自动标记需要人工复核的产品。

## 4. 优先级建议

综合考虑数据可得性、计算复杂度与业务价值，建议按以下优先级落地：

1. **P0 - 重仓股异动报告**：新进入 / 退出 / 增持 / 减持，最容易理解、最贴近业务需求。
2. **P1 - 集中度与换手率时序**：基于现有 `product_holding_summary` 即可快速实现。
3. **P1 - 行业配置漂移**：基于 `industry_name` 聚合，复用现有行业映射。
4. **P2 - 相似性网络时序**：复用 `similarity.py`，增加跨期对比。
5. **P2 - Brinson 归因跨期串联**：复用 `attribution.py`，增加报告期维度。
6. **P3 - 风格标签与异常信号**：依赖外部风格/估值数据，可作为后续增强。

## 5. 实现思路

### 5.1 新增数据表建议

为支持跨期分析结果持久化，建议新增：

- `product_holding_change`：单产品相邻两期持仓变化明细（股票级）。
- `product_holding_evolution`：单产品跨期汇总指标（换手率、集中度变化、行业漂移等）。
- `product_style_drift`：风格标签时序。
- `product_attribution_timeseries`：Brinson 归因结果时序（如尚未存储）。

### 5.2 计算流程

```
1. 选取产品 + 报告期序列
2. 对齐相邻两期持仓（按 asset_code + market）
3. 计算股票级变化（新增/退出/增持/减持）
4. 聚合到行业/资产类别维度
5. 计算汇总指标（换手率、重叠度、集中度变化）
6. 写入结果表
7. 可选：生成可视化报告或告警
```

### 5.3 与现有模块的衔接

- 复用 `fundseeker.similarity.similarity` 中的 `overlap_coefficient`、`jaccard_index`。
- 复用 `fundseeker.similarity.features` 构建产品-资产权重向量。
- 复用 `fundseeker.similarity.attribution` 的 Brinson 归因，扩展为时序输出。
- 复用 `fundseeker.similarity.industry` 的行业映射。

## 6. 风险与注意事项

- **报告期对齐**：公募基金季度报告披露存在滞后，分析时应以 `report_date` 为准，避免用 `collect_date` 替代。
- **新股/停牌/退市**：跨期比较时需注意 `asset_code` 的连续性与市场变化。
- **份额合并（AC 合并）**：基金 AC 份额在相似性分析中通常需要合并，持仓变化分析也应以合并后口径为主。
- **数据稀疏**：早期产品可能只有部分报告期数据，需处理缺失期。
- **市值与数量口径**：`market_value` 和 `share_quantity` 的单位和精度需与数据源保持一致，避免直接跨期比较不同单位。

## 7. 结合市场指标数据的增强分析

当前 `market_quote` 表已覆盖 A 股个股日线、主要宽基指数（沪深300、上证50、中证500、中证1000 等）及大宗商品行情。将持仓数据与市场行情交叉，可以把“持仓变化”从静态描述升级为“调仓效果评估”，显著提升分析的业务价值。

### 7.1 数据基础

| 数据来源 | 覆盖内容 | 关键字段 |
|---|---|---|
| `market_quote`（个股） | A 股日线 | `open_price`, `high_price`, `low_price`, `close_price`, `change_pct`, `volume` |
| `market_quote`（指数） | 宽基指数日线 | `close_price`, `change_pct` |
| `market_quote`（商品） | 黄金、布伦特原油 | `close_price`, `change_pct` |
| `product_holding` | 基金持仓明细 | `asset_code`, `market`, `weight`, `report_date` |
| `product_asset_allocation` | 大类资产配置 | `asset_class`, `weight`, `report_date` |

关联方式：`product_holding.asset_code + market` ↔ `market_quote.symbol_code`（如 `SH600519`）。

### 7.2 增强分析维度

#### 7.2.1 调仓时机判断

判断基金经理是在上涨前加仓、下跌前减仓，还是追涨杀跌。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 新进重仓股后续收益 | 取 `report_date` 后 N 日（如 20/60/120 日）个股收益率 | 选股前瞻性 |
| 退出重仓股后续收益 | 同上，计算退出后收益 | 规避能力 |
| 增持个股后续收益 | 按增持幅度加权计算后续收益 | 加仓准确度 |
| 减持个股后续收益 | 按减持幅度加权计算后续收益 | 减仓准确度 |
| 调仓方向胜率 | 新进/增持股票后续跑赢基准的比例 | 整体调仓质量 |

应用场景：识别“左侧布局型”经理（新进股票后续大涨）vs “趋势跟随型”经理（追涨后收益平平）。

参考案例与理论：
- Cohen, Polk, Silli (2010) 的 *Best Ideas* 研究表明，基金经理最重仓的“最佳想法”股票具有显著超额收益，验证了重仓股后续表现分析的价值。
- QuantPedia 的 [Alpha Cloning - Following 13F Filings](https://quantpedia.com/strategies/alpha-cloning-following-13f-fillings) 策略基于机构季度持仓披露构建克隆组合，是海外基于公开持仓做“跟随调仓”分析的成熟案例。

#### 7.2.2 行业配置与行业动量

将基金的行业权重变化与对应行业指数收益对比。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 行业超低配 vs 行业超额收益 | 计算基金行业权重 - 基准行业权重，对比报告期后行业指数收益 | 行业择时能力 |
| 行业轮动速度 | 相邻两期行业权重变化与市场行业收益的相关性 | 是否追逐热点 |
| 行业动量暴露 | 加仓行业过去 1-3 个月收益 | 动量/反转风格 |
| 行业集中度 vs 行业波动 | 行业 HHI 与对应行业指数波动率对比 | 风险暴露是否合理 |

应用场景：评估基金经理的行业轮动是否带来超额收益，还是仅仅增加了换手率和交易成本。

#### 7.2.3 大类资产择时能力

结合股票、债券、现金等资产配置比例与市场走势。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 股票仓位择时 | `stock_weight` 变化 vs 后续沪深300收益 | 股债择时能力 |
| 现金比例与市场波动 | 现金仓位 vs 后续市场波动率 | 防御性择时 |
| 行业 Beta 时序 | 用基金行业权重对指数做加权，估算组合 Beta | 市场风险暴露变化 |

应用场景：判断“低仓位在市场下跌前”是否为择时能力，还是运气。

参考案例与理论：
- Treynor-Mazuy (1966) 和 Henriksson-Merton (1981) 模型是基金择时能力的经典回归检验方法。R 语言 `PerformanceAnalytics` 包的 [MarketTiming](https://www.rdocumentation.org/packages/PerformanceAnalytics/versions/2.0.8/topics/MarketTiming) 函数提供了标准化实现。
- Jiang, Yao & Yu (2007) 等文献指出，基于持仓的择时测度相比基于净值的回归方法能更准确地识别基金经理的真实调仓能力。

#### 7.2.4 重仓股表现追踪

持续跟踪基金前十大持仓在报告披露后的市场表现。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| Top10 组合收益 | 按 `weight` 加权计算 top10 股票后续收益 | 核心持仓质量 |
| Top10 超额收益 | top10 组合收益 - 沪深300收益 | 相对基准的选股能力 |
| Top10 波动与回撤 | 加权组合的波动率、最大回撤 | 核心持仓风险 |
| 隐形重仓贡献 | 非 top10 但持仓较重的股票贡献 | 组合收益来源分解 |

应用场景：识别“核心持仓稳定且持续跑赢”的产品，或“前十大频繁更换但效果不佳”的产品。

#### 7.2.5 Brinson 归因的落地实现

文档第 3.7 节提到 Brinson 归因，结合 `market_quote` 可实现真正的收益分解。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 配置效应 | 行业权重差异 × 行业指数收益 | 行业择时贡献 |
| 选股效应 | 行业内个股超额收益 × 个股权重 | 个股选择贡献 |
| 交互效应 | 权重差异 × 个股超额收益 | 综合贡献 |
| 归因时序 | 每期归因结果按时间串联 | 能力稳定性 |

实现方式：复用现有 `fundseeker.similarity.attribution`，将个股收益从 `market_quote` 获取，基准可选沪深300/中证800行业权重（已有 `index_constituent_weight` 表支持）。

参考案例与理论：
- Brinson, Hood & Beebower (1986) 提出的 Brinson 模型是机构业绩归因的工业标准，广泛应用于 Bloomberg PORT、FactSet、Morningstar Direct 等资管系统。
- DolphinDB 提供了《[基于 DolphinDB 的 Brinson 绩效归因模型实践](https://docs.dolphindb.cn/zh/tutorials/brinson.html)》，包含单期与多期 Brinson、GRAP 收益修正算法的完整实现，适合作为工程落地参考。
- 华泰金工《析精剖微：机构拆解看北向资金》使用 Brinson 模型对北向资金持仓进行收益拆解，是国内基于持仓做归因分析的典型案例。

#### 7.2.6 风格因子暴露

利用已有市场价格数据和部分基本面代理变量，估算基金风格暴露。

| 风格 | 代理指标 | 用途 |
|---|---|---|
| 价值/成长 | 持仓股市盈率、市净率分位（需扩展基本面数据） | 风格标签 |
| 动量 | 个股过去 1-12 个月累计收益 | 动量/反转暴露 |
| 市值 | 个股流通市值或所属指数成分 | 大盘/小盘风格 |
| 波动率 | 个股历史波动率 | 低波/高波暴露 |
| 行业主题 | 个股所属行业与市场主题指数相关性 | 主题纯度 |

说明：完整风格因子分析需要补充个股基本面数据，但动量、波动率、市值等可先用 `market_quote` 实现。

参考案例与理论：
- Morningstar 的 [Equity Style Box](https://advisor.morningstar.com/Enterprise/VTC/ESBRecentered.pdf) 是基于持仓将基金按市值与价值/成长维度进行九宫格分类的国际标准工具，完全基于持仓数据实现风格画像。
- Fama-French 三因子/五因子模型及 Carhart 四因子模型为风格因子暴露提供了理论基础，其中动量、市值、价值因子均可通过市场价格数据初步估算。

#### 7.2.7 风险指标时序

将基金持仓组合视为股票组合，计算风险指标。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 组合波动率 | 按权重加权个股收益的标准差 | 持仓组合风险 |
| 组合 Beta | 组合收益对市场指数回归的 Beta | 系统性风险 |
| 组合最大回撤 | 组合净值从历史高点的最大回落 | 极端风险 |
| 组合夏普比率 | 组合超额收益 / 组合波动率 | 风险调整后收益 |
| 组合与基准跟踪误差 | 组合收益 - 基准收益的标准差 | 主动管理程度 |

应用场景：识别“高收益伴随高波动”还是“高收益伴随低风险”的产品。

参考案例与理论：
- 组合波动率、Beta、最大回撤、夏普比率、跟踪误差均为现代投资组合理论的标准指标，在 CFA 课程和 Bloomberg PORT、Morningstar Direct 等机构平台中均为标配。
- Sortino Ratio、Omega 等下行风险指标是夏普比率的补充，Morningstar 的 [Kappa: A Generalized Downside Risk-Adjusted Performance Measure](https://www.morningstar.com/research/signature?page=10) 对其进行了系统阐述。

#### 7.2.8 市场事件与持仓响应

分析基金在重大市场事件前后的持仓调整。

| 指标 | 计算方法 | 业务含义 |
|---|---|---|
| 事件前后仓位变化 | 市场大跌/大涨前后的 `stock_weight` 变化 | 应对能力 |
| 事件前后行业切换 | 事件前后行业权重变化 | 防御/进攻转换 |
| 事件前后重仓股变化 | 事件前后 top10 更替情况 | 调仓果断性 |

应用场景：评估基金经理在极端行情下的应对能力，如 2024 年初小盘股流动性危机、2025 年 AI 主题行情等。

### 7.3 实现建议

#### 7.3.1 新增结果表

- `product_holding_performance`：单期持仓在报告日后的收益表现。
- `product_holding_attribution`：Brinson 归因结果时序。
- `product_holding_risk`：持仓组合风险指标时序。
- `product_trade_timing`：调仓时机评价（新进/退出/增持/减持后续收益）。

#### 7.3.2 计算流程

```
1. 获取产品某报告期持仓（product_holding + product_asset_allocation）
2. 对齐 market_quote，计算 report_date 后 N 日个股/行业/指数收益
3. 计算 top10 组合收益、行业超低配收益、Brinson 归因
4. 计算风险指标（波动率、Beta、最大回撤、夏普）
5. 与上一期持仓变化关联，评价调仓时机
6. 写入结果表并生成时序报告
```

#### 7.3.3 与现有模块衔接

- 复用 `fundseeker.similarity.attribution` 的 Brinson 归因框架。
- 复用 `fundseeker.similarity.industry` 的行业映射。
- 复用 `market_quote` 作为收益数据源。
- 复用 `index_constituent_weight` 作为基准行业权重。

### 7.4 注意事项

- **披露滞后**：公募基金季报披露滞后约 15 个工作日，半年报/年报滞后更久，收益计算起点应使用 `report_date` 而非 `collect_date`，并在分析中注明披露滞后。
- **幸存者偏差**：退市、停牌个股可能在 `market_quote` 中无后续数据，需做缺失处理。
- **复权处理**：个股收益应使用复权价格，当前 `market_quote` 为原始价格，计算长期收益需补充复权因子。
- **AC 份额合并**：归因与风险分析应以合并后产品口径为准。
- **窗口选择**：不同分析目标适用不同收益窗口（短期 20 日、中期 60-120 日、长期 250 日）。

## 8. 总结

多期持仓变化分析能够从“静态相似性”延伸到“动态行为刻画”，帮助识别基金经理的调仓风格、能力圈稳定性、风格一致性以及潜在的异常信号。建议优先从重仓股异动、集中度变化和行业漂移三个维度切入，逐步扩展到风格漂移、归因时序和异常监控。

若能进一步结合 `market_quote` 的市场行情数据，则可进入“调仓效果评估”层面：不仅可以描述“基金变了什么”，还能判断“变对了没有”。其中，**调仓时机判断**、**Brinson 归因落地**、**重仓股后续表现追踪**和**组合风险指标时序**是投入产出比最高的四个方向，建议作为下一阶段重点落地。
