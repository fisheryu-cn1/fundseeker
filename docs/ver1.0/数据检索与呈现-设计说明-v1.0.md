## 2. 查询层（queries.py）

### 2.1 会话模式

```python
def _session():
    """每次调用创建独立 session，用完即关。"""
    engine = get_session_maker().kw["bind"]
    Session = get_session_maker(engine)
    return Session()
```

所有查询函数使用 `with _session() as session:` 上下文管理器，遵循 **session-per-query** 模式——每个查询创建独立会话，避免跨请求状态共享。这意味着嵌套调用（如 `market_summary()` 内部调用 `list_market_quotes()`）各自拥有独立会话，不会产生冲突。

### 2.3 Dataclass 返回类型

所有查询函数返回 **ORM-free dataclass** 或 `dict`，模板和 API 不直接接触 SQLAlchemy 对象。涉及 API 序列化的 dataclass 提供 `to_dict()` 方法，内部将 `Decimal`/`date`/`datetime` 转换为 JSON 兼容类型。

| Dataclass | 用途 | to_dict() |
|-----------|------|-----------|
| `ProductRow` | 产品搜索列表行 | ✅ |
| `HoldingReportRow` | 产品持仓报告时间线 | — |
| `HoldingRow` | 单产品持仓明细 | — |
| `AssetAllocationRow` | 大类资产配置 | — |
| `HoldingBrowseRow` | 跨产品持仓搜索行 | ✅ |

## 3. Web 应用层（app.py）

### 3.1 应用工厂

```python
def create_app() -> Flask:
    app = Flask(__name__,
                template_folder=str(TEMPLATE_DIR),   # .../web/templates
                static_folder=str(STATIC_DIR))        # .../web/static
    register_routes(app)
    register_filters(app)
    return app
```

### 3.2 参数解析辅助函数

| 函数 | 说明 |
|------|------|
| `_parse_date(value)` | `"YYYY-MM-DD"` → `date`；空/非法 → `None` |
| `_parse_int(value, default, min, max)` | 字符串 → 钳位整数；非法 → `default` |

### 3.3 Jinja2 过滤器（`register_filters`）

| 过滤器名 | 函数 | 输入 | 输出示例 |
|----------|------|------|----------|
| `fmt_money` | `float()` 后 `,:,.4f` | `Decimal("3.4567")` | `3.4567` |
| `fmt_pct` | `float()*100` 后 `,:,.2f%` | `0.0732` | `7.32%` |
| `fmt_date` | `strftime("%Y-%m-%d")` | `date(2026,7,1)` | `2026-07-01` |
| `fmt_dt` | `strftime("%Y-%m-%d %H:%M:%S")` | `datetime(...)` | `2026-07-01 21:30:00` |
| `holding_market` | → `queries.humanize_market` | `"SH"` | `上海` |
| `asset_class` | → `queries.humanize_asset_class` | `"stock"` | `股票` |
| `market_region` | → `queries.humanize_market_region` | `"domestic"` | `A股` |
| `fmt_volume` | `≥1e8 → "X.XX亿手"`；`≥1e4 → "X.XX万手"` | `12345678` | `123.46万手` |
| `fmt_amount` | `≥1e8 → "X.XX亿"`；`≥1e4 → "X.XX万"` | `5.67e9` | `56.70亿` |

所有数值过滤器对 `None`/空值返回 `"—"`，对 `Decimal` 类型先 `float()` 转换。

### 3.4 页面路由

| 路由 | 处理函数 | 模板 | 查询参数 |
|------|----------|------|----------|
| `GET /` | `search()` | `search.html` | `institution`, `type`, `risk`, `q`, `status`, `page` |
| `GET /product/<id>` | `product_detail()` | `product.html` | `report_id`（指定持仓报告） |
| `GET /holdings` | `holdings_browse()` | `holdings.html` | `asset_type`, `market`, `institution`, `q`, `report_date`, `top10`, `min_weight`, `page` |
| `GET /dashboard` | `dashboard()` | `dashboard.html` | 无 |
| `GET /market` | `market_dashboard()` | `market.html` | `date`（可选） |

#### 产品详情页特殊逻辑

1. 获取产品基本信息 + 净值 + 收益率 + 费率 + 最近日志
2. 获取持仓报告列表，解析 `?report_id=` 参数选择展示哪一期（默认最新）
3. 遍历持仓明细，按 `(asset_code, market)` 去重查询 `HoldingSecurityInfo`，构建 `security_info_map` 供模板注解
4. 净值数据反转后传给 Chart.js 折线图（`chart_labels` + `chart_values`）

#### 市场行情页特殊逻辑

1. `_parse_date()` 解析可选日期参数（无日期 = per-symbol 最新模式）
2. 对每个品种调用 `market_quote_history()` 构建 `chart_datasets` 列表
3. 将 `chart_datasets` 序列化为 JSON 嵌入模板，JavaScript 端 `makeChart()` 渲染双 Canvas

## 6. CLI 工具（fundseeker_query.py）

### 6.1 概述

`scripts/fundseeker_query.py` 是一个独立的命令行工具，复用 `fundseeker.web.queries` 中的全部查询函数，输出格式为 Markdown 文档，专为 OpenClaw 等 AI Agent 设计。

### 6.2 核心约束

```python
MAX_LINES = 2000
DEFAULT_PAGE_SIZE = 50
MAX_PAGE_SIZE = 200
```

- 输出上限 **2000 行**，超出后截断并在末尾追加截断提示
- 截断提示绕过行数上限，确保始终可见

### 6.3 `_Writer` 类

```python
class _Writer:
    lines: list[str]     # 追加的行缓冲
    cap: int             # 行数上限（默认 2000）
    truncated: bool      # 是否已触发截断

    def append(self, line: str) -> None: ...
    def extend(self, lines: Iterable[str]) -> None: ...
    def render(self) -> str: ...  # 拼接 + 必要时追加截断提示
```

### 6.4 格式化函数

| 函数 | 逻辑 |
|------|------|
| `_fmt_date(v)` | `date.isoformat()` / `datetime.strftime("%Y-%m-%d")` / `None → "—"` |
| `_fmt_pct(v)` | `float(v)` 后直接输出百分比数值（如 `3.45` → `"3.45%"`）。注意：此处期望输入已是百分比值（如 3.45），而非小数（0.0345），与 `MarketQuoteRow.change_pct` 的语义一致 |
| `_fmt_money(v)` | `float()` 后：`≥1e8 → "X.XX亿"`，`≥1e4 → "X.XX万"`，`≥1 → "X.XX"`，`<1 → "X.XXXX"`。兼容 Decimal/int/float/None |
| `_truncate(s, n=60)` | 超长字符串截断为 `n-1` 字符 + `…` |

### 7.2 per-symbol 最新查询（核心设计）

**问题**：不同品种的数据更新节奏不同——A 股/港股/美股指数在当前日期（如 2026-07-01）已有数据，但大宗商品可能在更早日期（如 2026-07-02）才有数据。如果直接用 `MAX(quote_date)` 过滤，只能得到该日期有数据的品种，可能遗漏其他品种。

**方案**：当 `quote_date=None`（默认/最新模式）时，使用 **关联子查询** 获取每个 `symbol_code` 各自的 `MAX(quote_date)`：

```python
latest_per_symbol = (
    select(
        MarketQuote.symbol_code,
        func.max(MarketQuote.quote_date).label("max_date"),
    )
    .group_by(MarketQuote.symbol_code)
    .subquery()
)
stmt = (
    select(*_MARKET_QUOTE_COLS)
    .join(
        latest_per_symbol,
        (MarketQuote.symbol_code == latest_per_symbol.c.symbol_code)
        & (MarketQuote.quote_date == latest_per_symbol.c.max_date),
    )
)
```

当 `quote_date` 明确指定时，直接按日期相等过滤。

## 8. 关键设计决策

### 8.1 session-per-query 模式

每个查询函数创建独立数据库会话，用完即关（`with _session() as session:`）。优势：
- 无跨请求状态泄漏
- 嵌套调用安全（各 session 独立）
- 无需显式 `session.close()`

代价：无法在一个事务中执行多个查询（本系统全部只读，不需要事务）。

### 8.2 ORM-free 返回类型

查询函数不直接返回 SQLAlchemy 模型实例（`get_product()` 等少数除外），而是返回 dataclass 或 dict：
- 模板不会意外触发懒加载
- API 序列化逻辑集中在 `to_dict()` 方法中
- Decimal → float 转换在 dataclass 层完成，模板无需感知

### 8.3 参数解析前移

`app.py` 中的 `_parse_date()` 和 `_parse_int()` 在路由层完成类型转换和校验，传入 queries 的参数已是正确的 Python 类型，queries 层不处理字符串。

### 8.4 CLI 的 `--min-weight` 语义

CLI 面向用户使用**百分比**作为输入（直观），内部除以 100 转为小数传给 queries。这种转换在 `render_holdings()` 中完成，queries 层保持数据库一致的小数语义。

### 8.5 惰性导入

`ProductReturn` 和 `ProductFee` 在 `list_returns()` / `list_fees()` 函数内部惰性导入，避免在这些表为空时影响其他查询函数的加载。

### 8.6 前端依赖

全部通过 CDN 加载，无本地构建步骤：
- Bootstrap 5.3.3 CSS + JS bundle
- Chart.js 4.4.4 UMD（仅在 market.html 和 product.html 中按需加载，通过 `{% block extra_js %}`）

### 8.7 涨跌颜色采用 A 股惯例

红涨绿跌（`text-danger` / `text-success`），在 dashboard.html、market.html、market KPI 卡片和明细表中一致使用。
